# Security policy

## Supported versions

Security fixes are made on the latest release of GroMo.

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues, discussions or
pull requests.

Report them privately with GitHub's
[private vulnerability reporting](https://github.com/growingnet/gromo/security/advisories/new).
The maintainers will acknowledge your report, keep you informed of its resolution,
and credit you in the security advisory if you wish.
